# Soul Link 화면 흐름

## 이번 단계

`인트로 영상 → 로비 → 모드 선택 → 대전 준비/초대방 → 대전 → 결과 → 로비`

- 인트로는 기존 Web 셸의 영상·로고·SKIP을 유지한다. Godot 진입 첫 화면은 로비다.
- 로비에는 현재 캐릭터 원화, AI 연습전, 초대 코드 대전, 도감과 향후 기능의 진입 자리를 둔다.
- AI 연습전은 캐릭터·상대 AI·스펠·보드를 고른 뒤 시작한다.
- 초대 코드 대전은 캐릭터·보드를 고른 뒤 방 생성/참가, 양쪽 준비 완료 시 서버 권위 전투로 진입한다. 온라인 스펠은 아직 비활성화한다.
- 화면 이동은 짧은 암전으로 연결한다. 결과에서는 로비로 돌아가며 AI전만 즉시 재대전할 수 있다.
- 상점, 랭킹, 전적/티어, 공개 매칭은 현재 비활성 자리 표시다. 가짜 큐·가짜 순위·가짜 구매는 제공하지 않는다.

## 다음 단계

1. 공개 매칭: 서버 큐, 취소/시간초과, 무료 한도, 재연결과 AI 대체 여부를 설계·구현한다. AI 대체는 실제 상대가 AI임을 명확히 표시한다.
2. 픽 단계: 공개 매칭 성립 후 양쪽이 캐릭터를 비공개 동시 선택하고 확정한 뒤 함께 공개한다. 초대방의 현재 `방 생성/참가 시 캐릭터 확정` 계약도 함께 변경해야 한다.
3. 스펠 단계: 온라인 스펠의 서버 규칙을 먼저 만든 뒤 선택/확정 단계를 연다.
4. 결과 저장: 서버 권위 경기 결과를 DB에 영구 저장하고, 시즌·티어·전적 정책을 확정한 뒤 로비/랭킹 UI를 연결한다.
5. 상점: 스킨만 판매/해금한다. 전투 성능과 중복 강화는 연결하지 않는다.

상성 보너스는 현재 5%이며 캐릭터를 본 뒤 카운터 픽하는 구조를 피하기 위해 동시 비공개 픽을 목표로 한다. 픽 화면은 서버 계약과 매칭 신뢰성이 준비된 뒤 구현한다.
