# 성좌 결투 (seongjwa)

- 기준 문서: claude.ai 프로젝트 "게임제작"의 '성좌 결투' 기획 패키지 v0.1.
  충돌 시 총괄 기획안 > 상세 탭 > 수치 테이블 xlsx. 코드는 기획 문서를 수정하지 않고, 불일치는 기획방으로 올린다.
- 전작 `soullink/`에서는 서버 구조와 유저 플로우만 가져온다(전작_점검.md). 퍼즐 전투·Toss·웹 패키징·기존 어드민은 가져오지 않는다.
- 게임 수치는 코드에 박지 않는다. xlsx → 백오피스 업로드(`server/src/bo/importer.mjs`, 검수·배포) → 데이터 버전 → 서버가 배포 스냅샷을 읽는다. `tools/import_balance.py`는 이전 CLI(시트 `경제` 미지원, 더 이상 쓰지 않음).
- 출시 전 인프라는 무료 플랜 테스트용(루트 AGENTS.md 규칙). 비밀값은 소스·로그·Git에 넣지 않는다.
- 변경 전 TASKS.md를 확인하고, 커밋은 이 폴더 범위로 한정한다.
